# Portfolio Website — Vishwajeet Prakash Karangale

> **Building at the intersection of AI, Technology & Entrepreneurship.**

This repository contains the source code for my personal portfolio website, designed to showcase my technical background, projects, learning journey, and entrepreneurial vision as a B.Tech CSE (AI & ML) student at REVA University.

---

## 🛠️ Tech Stack & Features

- **Frontend Architecture:** Modern semantic HTML5, CSS3 with CSS Grid, Flexbox, and CSS Custom Properties.
- **Visual Style:** Dark futuristic theme featuring glassmorphism cards, ambient blue-violet gradients, interactive lighting cards, and responsive layout structures.
- **Interactive Visuals:** High-performance HTML5 Canvas neural network particle animation that responds dynamically to cursor movements and frame updates.
- **Components & Interactivity:**
  - Dynamic skill matrix category filter.
  - Interactive learning journey tabs with progress tracking.
  - Modal overlay system for detailed project breakdowns (*KarigarSetu*, *KrishiSetu*, *Mind Eye*).
  - Built-in contact form state management with direct mailto link integration.
  - Fully responsive design optimized for mobile, tablet, and desktop viewports.
